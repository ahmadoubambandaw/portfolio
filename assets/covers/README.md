# Affiches d'accueil des projets (covers)

Place ici une image de couverture par projet. Le portfolio l'affiche
automatiquement sur la carte du projet et dans la fenêtre de détail.
Si le fichier n'existe pas, un fond dégradé de secours s'affiche.

Format conseillé : JPG ou PNG, ~1200 × 750 px (ratio ~16:10), le haut
de la page bien visible (l'image est cadrée depuis le haut).
